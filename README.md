<h1 align=center>NEU Cross-Spectral Stereo (NEU-CS2) Dataset<h1>

## 1.Data collection

> Following the steps below to collect data by yourself

### 📷 Hardware

+ Realsense D455i

+ Alienware PC

### 📂 Raw data structure

```bash
data
├── palce1
├── place2
├── place3
│   ├── d455.py
│   ├── scene0
│   │   ├── calib_ori.xml
│   │   ├── d455.py
│   │   ├── depth
│   │   ├── label_cre
│   │   ├── nir_nir
│   │   └── rgb
│   ├── scene1
│   │   ├── calib_ori.xml
│   │   ├── d455.py
│   │   ├── depth
│   │   ├── label_cre
│   │   ├── nir_nir
│   │   └── rgb
│   ├── scenex
│   ├── ...
```

> palcex--Data collection location
>
> scenex--Data collection scenes, scene0 does not open laser speckle for training (multiple pairs of images), while other scenes open laser speckle to obtain true values for testing (single pairs of images)
>
> calib_ori.xml--calibration data of D455i
>
> d455.py--data collection code
>
> depth--store label generated by realsense D455i
>
> label_cre--store label generated by crestereo using nir-nir pair
>
> nir_nir--store nir-nir raw data
>
> rgb--store rgb raw data

### 🏃🏾 How to run

1. make dirs following `Raw data structure`
2. move d455.py into `scenex` dir
3. run d455.py in `scenex` dir
4. run crestereo to generate `label_cre`
